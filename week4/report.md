For this weeks assignment I implemented global and local alignment using codon and python.
My global alignment uses the Needleman algorithm. Allegedly there is a recursive algorithm that uses far less space for the matrix but I was not bold enough to attempt that. I used a hardcoded gap penalty of -2, match penalty of 3 and mismatch penalty of -3. I had numerous issues with my lists being out of bounds so I changed the names of my indices so that they are more distinct.

I ended up running out of memory on my machine when testing with the long human/orangutang sequences so perhaps I should have recursively implemented the space efficient version after all. I did test with smaller sequences and it worked just fine. Chat gpt was good at helping me debug my index issues I've included some of my prompts in ai.md. For all of my prompts I did not specify that I was using codon. There were minimal differences between codon and python files so I just used python for the prompts.
